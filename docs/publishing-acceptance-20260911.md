## 真实 SSH 测试

使用 `scripts/testing/Dockerfile.ssh` 构建隔离 Linux 容器。容器内启动真实 sshd 和 Nginx，生成临时专用密钥，固定核验主机公钥，使用真正的 rsync、Next 静态导出和 Linux 符号链接切换。

通过项目：

1. SSH 连接与已固定的主机指纹校验，包括服务器 Banner。
2. 首次生成并上传，Nginx 可读取已选文章；未选草稿地址及其图片均返回 404。
3. 线上静态网站不提供内容工坊 API。
4. 第二次发布改变线上文章正文。
5. SSH 回退后，线上恢复第一次的正文；本地草稿仍然保留第二次修改。
6. 重新创建发布管理器后，当前发布基线仍正确。
7. 人为损坏远端旧版文件后，回退因校验失败而拒绝，当前网站不变。
8. 模拟丢失本地版本指针，通过核对远端实际版本恢复本地记录。

测试容器已自动删除，未暴露测试 SSH 端口到主机，未使用真实云端凭据。
